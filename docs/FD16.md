# AudioBus FD16 — Full-Duplex Fixed Point-to-Point Profile

FD16 is a fixed point-to-point full-duplex audio transport profile for ESP32-P4.

| Parameter | Value |
|-----------|-------|
| Audio IN per node | 16 channels |
| Audio OUT per node | 16 channels |
| Sample rate | 48,000 Hz |
| Sample format | signed 32-bit |
| Useful payload / direction | 16 × 32 × 48 kHz = 24.576 Mb/s |
| Transport frame | 72 bytes / sample period |
| Transport line rate | 27.648 Mb/s |
| Transport clock | 27.648 MHz, free-running |
| Coding | NRZ (no 8b10b) |
| Duplex | Full duplex (simultaneous TX/RX) |
| PHY | 1 × SN65LVDS049 per endpoint |
| Cable | Cat6A, 4 twisted pairs |
| Target distance | 50 m |

**Design invariant:** `27,648,000 / 576 = 48,000 Hz` exactly. Do not change
frame length, line rate, or sample rate independently.

---

## Frame format (72 bytes)

| Offset | Size | Field | Value |
|--------|------|-------|-------|
| 0 | 1 | SYNC0 | 0xA5 |
| 1 | 1 | SYNC1 | 0x5A |
| 2 | 2 | SEQUENCE | uint16_t big-endian, increments every frame |
| 4 | 1 | FLAGS | 0x22 (48 kHz / 32-bit / FD16) |
| 5 | 1 | CHANNELS | 16 |
| 6 | 64 | AUDIO | 16 × int32_t, big-endian (MSB first) |
| 70 | 2 | CRC16 | CRC-16-CCITT over bytes 0..69 |

CRC-16-CCITT: polynomial 0x1021, initial value 0xFFFF, no reflection, no final XOR.

---

## Clock tree

- **Node A (sole clock master):** Si5351A generates 27.648 MHz. This clock feeds
  (a) A's PARLIO TX `clk_in`, (b) A's PARLIO RX `clk_in`, and (c) SN65LVDS049
  DIN2 → DOUT2 → **Cat6A Pair 3** → Node B.
- **Node B (clock receiver):** received LVDS clock on RIN2 → ROUT2 → B's PARLIO
  TX and RX `clk_in` (both `PARLIO_CLK_SRC_EXTERNAL`, divider = 1, free-running).
  B's TX and RX are therefore phase-locked to A with zero frequency offset — no
  CDR and no independent crystal mismatch.

> **Note:** No Si5351A driver exists in this repository. The FD16 PHY reports
> the 27.648 MHz invariant but the actual Si5351A fractional-PLL register
> programming is a hardware-integration task to be added when a Si5351A driver
> is available. The `clk_out` pin (SN65LVDS049 DIN2) is wired by the board; the
> PHY does not gate or generate the clock.

---

## Cable pair assignment (Cat6A, 4 pairs)

| Pair | Signal | Direction | Notes |
|------|--------|-----------|-------|
| 1 | DATA A→B | A to B | 100 Ω LVDS, receiver termination at B |
| 2 | DATA B→A | B to A | 100 Ω LVDS, receiver termination at A |
| 3 | CLOCK A→B | A to B | 27.648 MHz LVDS, receiver termination at B |
| 4 | REF / shield | — | No power; shield/chassis/0 V strategy defined by system |

## Pin map (board-specific)

GPIO numbers are **not** fixed in firmware — they are configured via menuconfig:

```bash
idf.py menuconfig
# → "AudioBus FD16 Configuration" → "FD16 GPIO Pin Configuration"
```

| Kconfig symbol | Signal | SN65LVDS049 |
|----------------|--------|-------------|
| `ABUS_FD16_PIN_ROLE` | Role-select GPIO (1=master A, 0=slave B) | — |
| `ABUS_FD16_PIN_TX_DATA` | PARLIO TX data[0] | DIN1 |
| `ABUS_FD16_PIN_RX_DATA` | PARLIO RX data[0] | ROUT1 |
| `ABUS_FD16_PIN_TX_CLK` | PARLIO TX clock output (optional) | — |
| `ABUS_FD16_PIN_CLK_IN` | 27.648 MHz external clock (TX+RX) | DIN2 (master) / ROUT2 (slave) |
| `ABUS_FD16_PIN_CLK_OUT` | Clock driver input (master only) | DIN2 |
| `ABUS_FD16_PIN_I2C_SDA` | Si5351A I2C SDA (master only) | — |
| `ABUS_FD16_PIN_I2C_SCL` | Si5351A I2C SCL (master only) | — |

Also configurable: `ABUS_FD16_AUDIO_BUF_FRAMES`, `ABUS_FD16_CONCEALMENT_THRESHOLD`.
All pins default to `-1` (unassigned) until set from the board schematic.

**Role selection:** the node role is **not** chosen in menuconfig. It is read
from the `ABUS_FD16_PIN_ROLE` GPIO at startup: HIGH (1) = master A, LOW (0) =
slave B. The same firmware is flashed on both nodes; a jumper/pull-up/pull-down
on the role pin decides the role. If the pin is `-1`, the node defaults to
master (A).

## Electrical design constraints

- 100 Ω controlled-impedance differential routing for all LVDS paths.
- 100 Ω receiver termination physically close to receiving SN65LVDS049 pins.
- Keep PCB differential pairs short, symmetric, referenced to a continuous ground.
- Minimize vias/stubs between SN65LVDS049 and the cable connector.
- Low-capacitance ESD protection at the external interface only, after checking
  eye-opening impact.
- The Cat6A shield is not a DC common-mode reference; verify A/B ground offset
  (LVDS receiver common-mode range is finite).

> **Distance disclaimer:** 50 m at 27.648 Mb/s is a **validation target**, not a
> guarantee. TI specifies the SN65LVDS049 at up to 400 Mbps point-to-point over
> ~100 Ω media, but notes ultimate distance depends on attenuation, coupled noise,
> and application conditions.

---

## Link validation strategy

Do not accept "audio works" as proof of link margin. Use deterministic BER tests.

| Distance | Test | Pass criterion |
|----------|------|----------------|
| 1 m | PRBS31, both directions | BER ≤ 1e-12 |
| 10 m | PRBS31, simultaneous both directions | BER ≤ 1e-12 |
| 25 m | PRBS31 + eye diagram | BER ≤ 1e-12, adequate eye |
| 35 m | PRBS31 + eye diagram | BER ≤ 1e-12 |
| 50 m | PRBS31 + eye + common-mode | BER ≤ 1e-12 |
| 50 m / 24 h | continuous bidirectional stress | No unexplained sync/CRC burst |

Temperature characterization: approximately −10 °C, +25 °C, +50 °C. Record CRC
errors, sequence gaps, eye opening, and common-mode voltage.

---

## Error handling

| Condition | Action |
|-----------|--------|
| CRC failure | Drop frame; repeat last valid samples; increment `crc_errors` |
| Wrong sync/format | Drop frame; increment `sync_errors` |
| Unexpected sequence | Accept frame; increment `sequence_errors`; no retransmit |
| Consecutive bad frames ≥ threshold | Ramp/mute output (`concealment_threshold`) |
| TX underrun | Increment `tx_underruns`; clock stays free-running |
| RX overrun | Increment `rx_overruns`; resync at next frame boundary |

## Building

```bash
source $IDF_PATH/export.sh
idf.py set-target esp32p4
idf.py menuconfig            # → AudioBus FD16 Configuration → set GPIO pins
idf.py build
idf.py flash monitor
```

The project is FD16-only; legacy AudioBus PHYs and discovery/slot-map code are
not present.
